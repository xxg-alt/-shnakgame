# 食物与碰撞检测

## 食物系统

### 随机生成食物
```csharp
static (int x, int y) food;

static void SpawnFood()
{
    Random rand = new Random();
    food.x = rand.Next(1, width - 1);   // 不在边框上
    food.y = rand.Next(1, height - 1);
    Setcell(food.x, food.y, '*');         // 绘制食物
}
```

### 检测吃到食物
```csharp
if (Snake[0].x == food.x && Snake[0].y == food.y)
{
    score += 10;
    // 不删除尾部 → 蛇变长
    SpawnFood();  // 生成新食物
}
```

## 碰撞检测

### 撞墙检测
```csharp
static bool CheckWallCollision()
{
    var head = Snake[0];
    return head.x <= 0 || head.x >= width - 1
        || head.y <= 0 || head.y >= height - 1;
}
```

### 撞自己检测
```csharp
static bool CheckSelfCollision()
{
    var head = Snake[0];
    // 从第1个元素开始检查（跳过头部本身）
    for (int i = 1; i < Snake.Count; i++)
    {
        if (Snake[i].x == head.x && Snake[i].y == head.y)
            return true;
    }
    return false;
}
```

### 游戏结束
```csharp
if (CheckWallCollision() || CheckSelfCollision())
{
    GameOver = true;
    Console.SetCursorPosition(width / 2 - 5, height / 2);
    Console.Write("游戏结束!");
}
```
