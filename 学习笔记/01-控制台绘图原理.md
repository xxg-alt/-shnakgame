# 控制台绘图原理

## 核心概念

在控制台中绘制图形，本质是**向指定坐标写入字符**。

## 关键 API

```csharp
// 隐藏光标，避免闪烁
Console.CursorVisible = false;

// 设置窗口大小（列数, 行数）
Console.SetWindowSize(width + 13, height + 1);

// 移动光标到指定位置 (x=列, y=行)
Console.SetCursorPosition(x, y);

// 在当前位置输出字符
Console.Write(c);
```

## 封装函数

```csharp
static void Setcell(int x, int y, char c)
{
    Console.SetCursorPosition(x, y);
    Console.Write(c);
}
```

这样绘制任何东西只需要调用 `Setcell(x, y, '字符')`。

## 颜色控制

```csharp
Console.ForegroundColor = ConsoleColor.Yellow;  // 前景色
Console.BackgroundColor = ConsoleColor.Black;   // 背景色
```

## 注意事项
- 控制台坐标从 `(0, 0)` 开始
- X 轴是水平方向（列），Y 轴是垂直方向（行）
- 每次移动光标后写入，会覆盖原位置的内容
