# 蛇的移动逻辑

## 当前状态
蛇用 `List<(int x, int y)>` 存储身体坐标，头部在 `Snake[0]`。

## 移动原理

蛇的移动 = **头部新增一个点 + 尾部删除一个点**

```
移动前: [(3,5), (2,5), (1,5)]  ← 头部在左
移动后: [(4,5), (3,5), (2,5)]  ← 头部向右，尾部消失
```

## 实现步骤

### 1. 计算新头部位置
```csharp
int newX = Snake[0].x + DirX;
int newY = Snake[0].y + DirY;
```

### 2. 添加新头部
```csharp
Snake.Insert(0, (newX, newY));
Setcell(newX, newY, 'O');  // 绘制新头部
```

### 3. 删除旧尾部
```csharp
var tail = Snake[Snake.Count - 1];
Setcell(tail.x, tail.y, ' ');  // 清除尾部显示
Snake.RemoveAt(Sn�ke.Count - 1);
```

### 4. 更新头部标记
```csharp
// 原来的头部变成身体
Setcell(Snake[1].x, Snake[1].y, '0');
```

## 方向控制

用 `DirX` 和 `DirY` 控制移动方向：
| 方向 | DirX | DirY |
|------|------|------|
| 右 → | 1 | 0 |
| 左 ← | -1 | 0 |
| 下 ↓ | 0 | 1 |
| 上 ↑ | 0 | -1 |
